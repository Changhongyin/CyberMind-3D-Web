Compiled from the competition-page screenshots supplied by the user in this conversation. This is a transcription of observed fields, not the complete or freshly verified competition rules. ## Observed requirements
- The entry must use Aholo Lux3D. Other tools may be combined with it.
- Topic fields: project name and a short introduction explaining what you want to make, who it is for, and how Lux3D contributes. The short introduction should preferably stay below 100 Chinese characters, following the user's preference; this is not a confirmed competition character limit.
- Required deliverable: a complete runnable Demo link OR a demonstration/promotional video containing real footage of the running work, provided by link or file upload. A ModelScope Studio link is recommended on the page, not stated as mandatory.
- Required project report: PDF/PPT or a report link. Include production-process screenshots and key asset iterations/comparisons or key-result screenshots. Links must be accessible to judges.
- Required form fields also include ecosystem partner equipment/technology used (select truthfully; None is available) and application tracks (select 1-3 actual applicable categories, or None when not entering a category).
- Visible application categories: games, spatial design, film/video, 3D printing, embodied intelligence. These are form categories, not a requirement to create all these types.
- Optional bonus: a Xiaohongshu post with #Aholo黑客松; one registered social link per work. Do not fabricate a post or publish one without authorization.
- Optional bonus: project source code via project/repository link OR ZIP/RAR upload. The screenshot explicitly limits this source-code archive upload to 500 MB. That limit must not be assumed to apply to the separate video or report fields.
- Final declarations require truthful use of Aholo Lux3D, a runnable/demonstrable entry, and agreement to competition submission terms.
- The page states submissions can be updated before the deadline and judging uses the last successful submission before November 19 at 19:00. Confirm the current official year, timezone, deadline, eligibility and rules before relying on them.
