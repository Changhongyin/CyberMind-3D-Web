# Selected technical references

These support implementation and honest performance reporting; they are not the product's artistic brief.

- Browser animation callbacks and display refresh: https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame
- Web video callbacks and playback/display rate: https://developer.mozilla.org/en-US/docs/Web/API/HTMLVideoElement/requestVideoFrameCallback
- Geometry batching: https://threejs.org/manual/pages/optimize-lots-of-objects.html
- Instanced geometry: https://threejs.org/docs/pages/InstancedMesh.html

Use the documentation for the actual installed/pinned library and renderer version. Do not assume an experimental renderer, codec or feature is available without checking.
